# Final narration — Siren v4

A hundred contributors. One repository. And they're all changing the same file.

This is a real local test of Source, with a hundred scripted agent processes running together. Each works in its own clone and changes a different section of the file.

Watch the edits arrive. Each submission keeps its own commit and identity.

Source brings those changes into one candidate. It won't accept that candidate before the required verification passes.

Then the verified commit lands on main. All one hundred contributions are still there. We checked the contents and the history, and compared the final tree with a sequential merge of the same changes.

This tests compatible edits to one file. Conflicting edits to the same lines are a different case.

Source, version zero point two. Try it alongside the setup you already use.
